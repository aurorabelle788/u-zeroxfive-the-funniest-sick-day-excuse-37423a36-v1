## What it does

`main.ts` writes a single line — the funniest sick-day excuse — to `/output/entry.txt`. The line is fixed and deterministic: the same line on every run.

## Run

```sh
node main.ts
```

Requires Node 22 or later. Standard library only, no dependencies, no network.
